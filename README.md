## 🚀 Featured Projects

### 🏥 [Cosmetic Clinic](https://github.com/mohamedtalaat172002/CosmoticClinic)
A full ASP.NET Core 8 solution for a cosmetic clinic: a public MVC website, an admin dashboard, and a versioned REST API.

- Treatment catalogue and article journal with search, pagination, and SEO-friendly slugs
- Consultation request flow from the public site to the admin area
- Admin dashboard for managing clinic settings, treatments, articles, and consultations
- JWT authentication with refresh tokens, reset password, and role-based authorization
- Arabic / English localization
- Multi-image galleries hosted on Cloudinary, including cleanup of old assets
- Clean Architecture with MediatR, FluentValidation, Repository + Unit of Work, Serilog + Seq

**Stack:** ASP.NET Core 8 · MVC · Web API · EF Core · SQL Server · Identity · JWT · Cloudinary · Docker

---

### 🏫 [School API](https://github.com/mohamedtalaat172002/SchoolApi)
An API for managing school operations (students, departments), built on .NET 8 with Clean Architecture.

- CQRS with Mediator pattern
- Pagination, searching (by name or address), and ordering (by name, department, or id)
- Validation with FluentValidation and Data Annotations (e.g., preventing duplicate student names)
- Arabic / English localization with dynamic language switching
- Standardized General Response Handler (metadata, success flag, error messages)
- Repository Pattern and AutoMapper for entity-to-DTO mapping

**Stack:** .NET 8 · EF Core · SQL Server · MediatR · FluentValidation · AutoMapper
